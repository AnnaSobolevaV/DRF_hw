# DRF_hw
В рамках домашней работы реализована бэкенд-часть SPA веб-приложения - обучающие курсы.

Приложение позволяет создавать, редактировать, удалять и просматривать Курсы и Уроки в этих курсах. 
А так же реализована рассылка писем пользователям об обновлении материалов курса по подписке;

Реализованы эндпоинты:
    Регистрация пользователя.
    Авторизация пользователя.
    Создание Урока.
    Редактирование Урока.
    Удаление Урока.
    Просмотр Урока.
    Создание Курса.
    Редактирование Курса.
    Удаление Курса.
    Просмотр Курса.
    
Настроено приложение для работы с периодическими задачами;
Добавлена асинхронная рассылка писем пользователям об обновлении материалов курса по подписке;
Реализована периодическая задача, которая проверяет пользователей по дате последнего входа и блокирует их;
Настроен проект для работы с Celery;


Для запуска проекта необходимо:
1. клонировать репозиторий: git clone https://github.com/AnnaSobolevaV/DRF_hw.git 
2. установить окружение и зависимости (для управления зависимостями использован poetry.(см. pyproject.toml) )
3. файл с переменными окружения (.env.exmpl) необходимо заполнить и сохранить с именем .env
4. настроить базу данных и выполнить миграции
5. запустить Redis
6. запустить планировщик задач Celery: celery -A config worker --beat --scheduler django --loglevel=info


Для запуска проекта через Docker необходимо:
1. выполнить команду 
    docker-compose up -d --build  
2. после того как образ соберется и запустится контейнер с сервисами, успешность можно проверить командой:
    docker-compose ps

Для настройки удаленного сервера и ручного деплоя приложения необходимо выполнить следующие шаги:
- настроить виртуальную машину например на платформе Yandex Cloud. (Проект реализован для ОС Ubuntu.)
- запустить ВМ и подключиться к ней через терминал по команде ssh ваш_пользователь@IP_адрес_машины
- выполнить команды:
  - sudo apt update
  - sudo apt upgrade
- установить Docker https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository.
- выполнить команды:
  - sudo ufw enable
  - sudo ufw allow 22/tcp
  - sudo ufw allow 80/tcp
  - sudo ufw allow 443/tcp
  - sudo apt update 
  - sudo apt install git 
  - git clone --branch hw_35_2 https://github.com/AnnaSobolevaV/DRF_hw.git
  - cd DRF_hw
- файл с переменными окружения (.env.exmpl) необходимо заполнить и сохранить с именем .env
  - sudo docker compose up -d --build
